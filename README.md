# 🎯 Number Guessing Game – C++

A beginner-friendly console-based number guessing game built using C++.

## 📌 About

This is one of my first C++ projects, created while learning programming fundamentals and Data Structures & Algorithms.

The program asks the user to guess a number and provides feedback after each attempt until the correct number is guessed.

## 🛠️ Concepts Used

- Variables
- Input and Output
- Conditional Statements
- Loops
- Functions
- Pass-by-Reference
- Basic Problem Solving

## 🎮 How It Works

1. The program selects a number.
2. The user enters a guess.
3. The program tells the user whether the guess is too high or too low.
4. The process continues until the correct number is guessed.
5. The number of attempts is displayed at the end.
